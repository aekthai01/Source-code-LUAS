# Audit fixes applied after the first reconstruction checkpoint

This file records corrections made after re-auditing the generated source against the attached known-good baseline.

## Runtime fidelity fixes

1. **JSON module paths/signatures corrected**
   - primary: `Common.Components.dkjson.decode(text, 1, nil)`
   - secondary: `DFM.YxFramework.Plugin.Json.Json.createJson()` then `decode(text)`

2. **CommonTips bridge corrected**
   - uses `_G.Module.CommonTips.ShowSimpleTip`
   - removed unsupported `require("DFM.Business.Module.CommonTips")`

3. **`ULuautils.GetStringFromBytes` ABI corrected**
   - plain call with the byte value as its only argument
   - no invented `self` argument

4. **Active device-ID source corrected**
   - `DEVICE_ID` is a field of the wrapper's private config table captured by prototype `0.31`
   - `_G.DEVICE_ID` is not read by the active baseline auth path
   - legacy prototype `0.18` is overwritten before auth closure creation and is documented as unreachable from the active login path

5. **HttpLoader completion lifecycle restored**
   - one-shot `done` guard
   - `evtOnBatchComplete:Unbind(callback, caller)` before release
   - `Release()` once
   - final callback once

6. **HttpLoader callback body semantics corrected**
   - prototype `0.16.1` consumes callback parameter 3 (`R2`) as the payload
   - it no longer scans unrelated callback metadata/status arguments for a string

7. **Lobby module late-availability gap fixed**
   - current Lobby stage is checked synchronously
   - `evtLobbyBusinessInit` is bound when available
   - if the module is not ready yet, only listener registration is retried at 1 s, max 60 attempts
   - no automatic UI reopen/watchdog loop was introduced

8. **Manual globals ordering fixed**
   - `OpenSpectraLogin` and `OpenSpectraControl` are installed before saved-key authentication starts
   - this is safe even if a transport invokes its completion callback synchronously

## Validation/report fixes

- `validation.json` is now regenerated by `tools/validate.py` on every `tools/build.py` run.
- deterministic protocol fixture added with fixed card/device/timestamp/challenge/sign/cipher/wire URL.
- direct opcode evidence is now reported as **44/47**; raw `8`, `36`, `46` are explicitly inferred-only because they do not occur in outer or payload chunks.
- baseline wrapper call graph added in `WRAPPER_CALL_GRAPH.md` and `wrapper_call_graph.json`.
- exact baseline copy added as `baseline_original.luac`.
- unexplained `texluac.out` removed from the deliverable.
