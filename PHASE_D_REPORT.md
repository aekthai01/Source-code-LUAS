## Transactional aim bridge

Rollback verifies every captured field and bone array record before payload delegation.
For bone arrays it checks captured counts, canonical values at each index, owner bindings,
parent-array entries and parent-owner links. An incomplete restore retains both snapshots
and the bone-name pool, records `bone rollback incomplete`, and blocks payload delegation.
Regression tests create two real bone records and cover a failed second array, a failed
owner binding, a failed index with a restored binding, and the all-record success path.

`src/spectra/payload_feature_bridge.lua` now owns `aim` and `anti_shake` after the payload
initializes. It preserves both original payload globals.

Installation behavior:

- all dependencies present: install source `P73` and source `P77` together
- dependency missing: payload globals remain unchanged
- halfway global replacement failure: both payload globals are restored

Execution fallback behavior:

- source mutation failure restores source snapshots/state
- known-good payload implementation is called once
- fallback does not recurse into the source wrapper
- delayed `P77` callbacks retain source `P73`; they do not re-resolve a replaced global
